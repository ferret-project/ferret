# Needs attention

The **bell** in the top bar lists what needs doing now, with a count — red when something's urgent. It's a list of
things to do, not messages: an entry disappears once it's dealt with.

![The bell open: something to buy, possible recalls, and maintenance due](/screenshots/attention-light.webp){.shot .light-only}
![The bell open: something to buy, possible recalls, and maintenance due](/screenshots/attention-dark.webp){.shot .dark-only}

| What | When |
|---|---|
| Maintenance | Overdue, or due within a week (urgent once it's due) |
| Warranties | Ending within a month (urgent within a week) |
| Returns | The last day to [return something](./warranties#return-windows) is within a week (urgent for the last two days) |
| Claims | No news for two weeks — time to follow up |
| New items to name | Added from photos and not confirmed yet |
| Things to buy | One entry for the [shopping list](./stock#shopping-list) — urgent once something's run out |
| Keeping track | Things nobody can find, and things not seen in a year — [review a room](./room-review) (never urgent) |
| Backups | Failing, or none lately — for [the server admin](../hosting/server-admin) only |

Urgent entries are also what the [daily reminder](./reminders) sends.
